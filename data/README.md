# Raw data

The raw files are not in this repository. Download the dataset from Kaggle and put the CSV files in `data/raw/`:

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The scripts use these eight files (the geolocation file is not needed):

- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `product_category_name_translation.csv`

The data is released under CC BY-NC-SA 4.0. It is real but anonymized.
